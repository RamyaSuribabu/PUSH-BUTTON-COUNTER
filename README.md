*Description

In this task, a push button is used as an input device to increment a counter displayed on an I2C-connected LCD screen via an Arduino. Each press of the button is detected, and the counter value increases accordingly. To prevent noise interference or unintended counts due to the mechanical nature of buttons, a debounce mechanism is implemented using a time delay. The LCD displays the current count and provides visual feedback, while the Serial Monitor logs the button state and counter value for real-time monitoring and debugging. This task combines hardware components, such as the button and LCD, with software logic to create an interactive system with practical applications in tallying, tracking, or entry systems.
